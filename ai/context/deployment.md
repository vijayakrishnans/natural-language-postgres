## Model

| environment | writes the SQL |
|---|---|
| stage | Workers AI's Llama 4 Scout (the AI binding) — no OpenAI key set |
| prod | Workers AI's Llama 4 Scout (the AI binding) — no OpenAI key set |

Workers AI bills the Cloudflare account the Worker runs in, after its free
daily allocation. No AI vendor is brokered by the platform: OpenAI's key is a
Worker secret the owner adds per environment (README, "Use OpenAI
instead"). Whichever model writes it, the SQL runs as `query_reader`, which
can read the `unicorns` table and nothing else.
